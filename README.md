# Industrial Safety with Deep Learning

This project detects PPE violations using YOLOv8 in real-time and generates voice alerts.

## Features
- Detects: Hardhat, Mask, Safety Vest
- Alerts for: No-Hardhat, No-Mask, No-Safety Vest
- Real-time webcam monitoring

## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```

## Model
Trained YOLOv8 model to detect PPE.
